# HeroBoxd

**Demo estática para descobrir histórias de heróis e registrar suas próprias notas.**

🌐 **[Abrir a demo](https://quadrosmatheus.github.io/heroboxd-demo/)**

## O que dá para fazer

- Explorar 16 títulos de filmes, séries, jogos e HQs.
- Pesquisar, filtrar por formato e ordenar o catálogo.
- Dar notas de 1 a 5 estrelas e montar uma estante pessoal.
- Alternar entre tema claro e escuro; usar no celular ou computador.

## Como funciona

A demo publicada é feita com HTML, CSS e JavaScript e não usa servidor, conta ou banco de dados. Suas notas e sua estante ficam no armazenamento local do navegador, apenas neste dispositivo. Não são compartilhadas com outros visitantes e podem ser perdidas ao limpar os dados do navegador.

Para experimentar, abra o link acima e clique nas estrelas ou em **Minha estante**. Não é necessário instalar nada.
